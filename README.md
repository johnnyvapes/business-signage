# Bellevue Business Signage

## Replacing promotional images

The five promotional slots are intentionally simple. Replace the image in `media/` using the same filename:

- `media/promo1.jpg`
- `media/promo2.jpg`
- `media/promo3.jpg`
- `media/promo4.png`
- `media/promo5.png`

You do not need to edit `index.html`. Commit the replacement image to GitHub and GitHub Pages will deploy it. The signage page also reloads periodically so a running Chromecast can pick up replacements.
